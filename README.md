1. Uygulamanın Amacı
Bu projenin amacı; kullanıcıların girdikleri şehirlerin anlık hava durumu verilerini öğrenebilecekleri, asenkron (sayfa yenilenmeden)
çalışan dinamik bir web uygulaması geliştirmektir. Proje, HTML ve CSS ile tasarlanmış sade bir arayüz üzerinde, JavaScript ve jQuery 
kullanılarak istemci taraflı etkileşimlerin yönetilmesini hedeflemektedir.

2. Çalışma Mantığı ve Kullanılan Teknolojiler
Uygulama temel olarak kullanıcının girdiği şehir bilgisini alıp, OpenWeatherMap API'sine bir istek gönderir ve dönen JSON formatındaki
veriyi işleyerek ekrana yazdırır.
